# bro

Restate **your own most recent message** (the last substantive reply you sent before this) in simpler, everyday English.

## What to do

1. Look back at the last meaningful message you sent — the explanation, summary, or answer the user is reacting to.
2. Rewrite that same content in plain English:
   - No jargon. If a technical term is truly unavoidable, define it in everyday words right there.
   - Short sentences. One idea each.
   - Use concrete analogies or examples where they make an abstract point land.
   - Keep the actual meaning and any important caveats — simpler wording, not less accuracy.
3. Keep exact identifiers precise — real file names, commands, code, numbers, and API names stay as-is (renaming them would be wrong). Only the *prose around them* gets simpler.

## What NOT to do

- Don't add new information, new opinions, or extra analysis — this is a re-explanation of what you already said, not a fresh take.
- Don't just delete the hard parts — explain them simply instead. If something genuinely can't be simplified, say so in one plain sentence and give the closest everyday approximation.
- Don't be condescending. Simple ≠ talking down.

## Output

Just the simpler version. No preamble like "Sure, here's the simpler version" — lead with the rephrased content.
